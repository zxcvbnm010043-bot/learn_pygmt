🌍 PyGMT：Python 地理空間繪圖利器

一個為地球科學家打造，將強大 GMT 功能引入 Python 的介面。

🧐 PyGMT 是什麼？

PyGMT 是一個開源 Python 庫，它為著名的 Generic Mapping Tools (GMT) 提供了 Python 接口。

GMT 是一個在地球科學領域廣泛使用的命令行工具集，而 PyGMT 的目標是：

  • 讓 GMT 的功能對 Python 用戶更友好。
  • 將數據處理和繪圖流程整合到 Python 環境中。
  • 輕鬆製作出出版品質 (Publication-Quality) 的地圖和圖形。

🚀 核心優勢

  • Pythonic API: 使用面向對象的語法，如 fig.coast()，直觀且易於學習。
  • 強大的底層: 繼承 GMT 的所有功能，包括投影、網格處理、色彩映射等。
  • 與 Python 生態系統整合: 可輕鬆搭配 NumPy, Pandas, Xarray 等主流科學計算庫。
  • 現代執行模式: 依賴 GMT 6 的現代模式，大幅簡化繪圖命令。

💡 入門範例：繪製海岸線

以下程式碼展示如何快速繪製台灣周邊的海岸線圖：

import pygmt

# 1. 建立一個圖 (Figure) 對象
fig = pygmt.Figure()

# 2. 使用 .coast() 函數繪製海岸線
fig.coast(
    # 地圖範圍: [西, 東, 南, 北] 經緯度
    region=[119, 123, 21, 26],
    # 投影方式: Mercator 投影，寬度為 10 公分
    projection="M10c",
    # 繪製陸地和水域的顏色
    land="#e0e0e0", # 淺灰色陸地
    water="skyblue", # 淺藍色水域
    # 繪製邊框與經緯線
    frame="a"
)

# 3. 儲存圖片 (範例將儲存為 PNG 檔)
# fig.savefig("taiwan_coast.png")

# 4. 在 Jupyter/Colab 環境中顯示圖片
fig.show()

📚 深入學習 PyGMT 的常用功能

1. 繪製點資料 (Scattering Points) - 使用 `fig.plot()`

fig.plot() 是繪製點、線或多邊形的核心函數。它非常適合標記地震、測站或採樣點等位置。

import pygmt
import pandas as pd # 常用於載入點資料

# 假設有一份包含緯度 (lon), 經度 (lat), 大小 (size) 的點資料
data = pd.DataFrame({
    "lon": [121.56, 120.20, 121.78],
    "lat": [25.04, 23.00, 24.97],
    "size": [0.5, 0.8, 0.6] # 圓圈大小 (c) 或顏色 (C)
})

fig = pygmt.Figure()
fig.coast(region=[118, 124, 21, 27], projection="M10c", frame="a", land="tan")

# 使用 plot 繪製點資料
fig.plot(
    x=data["lon"], # 經度
    y=data["lat"], # 緯度
    style="c", # 圓圈 (circle)
    size=data["size"] + "c", # 設定點的大小 (單位為公分 c)
    color="red", # 點的顏色
    pen="1p,black", # 點的邊框
    label="重要測站" # 可選的圖例標籤
)

# fig.show()

2. 處理網格資料 (Gridding Data) - 使用 `fig.grdimage()` 與 `fig.contour()`

PyGMT 擅長處理網格數據 (如地形、溫度分佈)，並利用 GMT 的網格處理工具 (如 grdsample, grdcut)。最常用的繪圖指令是：

  • fig.grdimage(): 繪製彩色網格圖。
  • fig.contour(): 繪製等高線。
# 示範：載入 PyGMT 內建的地球地形網格資料 (Earth Relief)
fig = pygmt.Figure()

# 1. 取得網格資料 (例如 15 弧秒解析度)
# 這行程式碼會自動下載資料
grid = pygmt.datasets.load_earth_relief(resolution="15s", region=[120, 122, 22, 25])

# 2. 建立色彩映射表 (Color Paletter Table, CPT)
pygmt.makecpt(
    cmap="topo", # 地形顏色
    series=[grid.min(), grid.max()] # 顏色範圍
)

# 3. 繪製彩色地形網格圖
fig.grdimage(
    grid=grid,
    region=[120, 122, 22, 25],
    projection="M6c",
    frame=["a", "+t臺灣地形圖"]
)

# 4. 繪製顏色條 (Colorbar)
fig.colorbar(frame=["a500f100", "x+lElevation", "y+lm"])

# fig.show()

最推薦且最簡單的安裝方式是使用 Conda/Mamba，它會自動處理 GMT 的依賴：

conda install -c conda-forge pygmt
